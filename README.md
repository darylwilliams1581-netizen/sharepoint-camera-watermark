# FieldCam — SharePoint camera app with watermark

Take a photo on a phone or laptop, bake a watermark into the JPEG (timestamp, GPS, user, caption), then upload it to a SharePoint document library.

Two ways to run this:

1. **This web app** (best watermark quality — the stamp is part of the image file)
2. **Power Apps + Power Automate** (fastest if your team already lives in Microsoft 365)

See the full source in this repository: `index.html`, `styles.css`, `app.js`, and `docs/`.
